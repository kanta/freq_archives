freq シリーズの活動をさらに拡張し、音＋映像、＋メディア、＋WEB、＋コミュニティなど、音に関わる取り組みで活躍する作家を招いて、その実験的な試みを発表・議論するイベント。平成23年度福岡市民芸術祭参加。

freq 本体ではなく、freq の関連イベントです。イベント名は「re:re:freq」「Re:Re:freq」の両方の表記があります。後援欄の財団名は元のページの表記のままです。
