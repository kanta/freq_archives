同時期の実験音楽イベント月間「experimental month(s)」（2002年10月14日〜12月8日）の一部として開催。月間の8イベントはアーカイブ内の ex-months に記録されています。

出演者の表記は当時のページのままです（Robert Dockworth / Duckworth の揺れも直していません）。
