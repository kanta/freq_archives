nyantora と duenn によるアンビエント・イベント「Hardcore Ambience」との共同企画。録音スタジオ・無響室・残響室を会場に、ライブパフォーマンスを行いました。無響室と残響室の公演は入れ替え制でした。

タイムテーブルは A〜D の4種類があり、ここでは A を載せています。情報は当日のリーフレットによります。

タイムテーブル（A）

  • 18:10–18:40 monogs（1F録音スタジオ）
  • 18:45–19:15 nyantora + duenn（2F無響室）
  • 19:20–19:40 城一裕（1F録音スタジオ）
  • 19:45–20:15 日山豪（1F録音スタジオ）
  • 20:20–20:40 松浦知也（1F録音スタジオ）
  • 20:45–21:00 牟田春輝（B1F残響室）
