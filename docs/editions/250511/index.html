音の始源を求めて

「音の始源を求めて」との共催によるコンサート『NIPPON 電子音楽70周年記念』。1950年代に始まる日本の電子音楽（黛敏郎の「X・Y・Z」、日本初の電子音楽作品「素数の比系列による正弦波の音楽」など）を振り返る。
