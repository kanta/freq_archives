FREQ2018 ―21世紀初頭の音と音楽―

2018

日時
2018年3月29日（木）〜30日（金）
会場
九州大学大橋キャンパス 音響特殊棟（無料）
主催
九州大学芸術工学部 音響設計学科 城研究室
ゲスト
金子智太郎（トーク）
比嘉了＋すずえり（パフォーマンス）
出展・出演
城一裕
松浦知也
Cycaq
谷川穂高
吉村帆生
帯屋健之
清水久見

城研究室の学生による作品・研究の発表に加え、美術の中の音に焦点を当てた「日本美術サウンドアーカイヴ」の企画者である金子智太郎と、即興デュオの比嘉了＋すずえりをゲストに迎え、技術と美学の両面から、いまの音と音楽のあり方を示す展示・トーク・パフォーマンス。

スケジュールと作品はパンフレットによります。科研費 若手研究（A）「ポストデジタル以降の音を生み出す構造の構築」（JP17H04772）の助成によるもの。

スケジュール

  • 3月29日 14:00–18:00 展示（2F無響室／1F調整室）
  • 3月30日 10:00–20:00 展示（2F無響室／1F調整室）
  • 3月30日 17:00–18:00 トーク（前半）（1Fスタジオ）
  • 3月30日 18:00–20:00 パフォーマンス（1Fスタジオ）
  • 3月30日 20:00– トーク（後半）（1Fスタジオ）
