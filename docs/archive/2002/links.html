FREQと関係のあるイベントや団体など
experimental month(s)
FREQ02も含めた、2002年秋に福岡で行われる実験的な音楽イベントを「experimental month(s)」という名前で展開しています。
website :: http://www.kyushu-id.ac.jp/~snlab/freq/2002/ex-months/

experimental month(s) presents: Joel Ryan [LIVE & LECTURE+]
10/16、九州芸術工科大学にて行われる、オランダの研究所steimよりジョエル・ライアンを招いての、ライヴとレクチャーです。
website :: http://www.kyushu-id.ac.jp/~kanta/event/joel/

sonarsound tokyo
バルセロナで開催されて既に9年の実績をもつ、エレクトロニック・ミュージックとデジタル・アートの祭典「SONAR」の日本版。TOKYO DESIGNERS BLOCK 2002の一環のイベントとして開催されます。
website :: http://www.sonarsound.jp/

ARch in ISEA2002
名古屋で開催される、世界各地の電子音響アーティストの出演するフェスティバルです。「電子芸術国際会議2002名古屋」の一環として行われます。
website :: http://arch-project.com/isea/

rhythm
福岡のアート批評誌。experimental month(s) や <frequency / rhythm> をFREQと共催しています。
website :: http://rhythm_com.tripod.co.jp/
