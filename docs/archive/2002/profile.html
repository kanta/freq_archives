Robert Duckworth
　ニューメディア・アーティスト。
　1999年ジョージア大学卒業（BMUS Music Composition）。
　現在、The California Institute of The Artsにおいて、Mark Trayle 氏のもと、Art Degreeの修得の為Composition New Media 学科のマスターコースに在学中。Tom Erbe, Wadada Leo Smith, Morton Subotnick, James Tenneyなどに師事。また、同大学の電子音楽スタジオで、Teaching Assistant として働いている。
　１０代のころからパーカッションに興味を抱き、その後、作曲と音楽理論をジョ ージア大学においてLewis NielsonとLeonard V. Ball, Jr.に師事するにいたる。同大学在学中、日本文化と日本語を学ぶ。
　ジョージア大学卒業後、Pierre Boulez (Carnegie Hall), Julio Estrada (CCMIX), Gerard Pape (CCMIX), Miller Puckette (SUNY),Curtis Roads (CCMIX), Karlheinz Stockhausen (Kurten,Germany), David Zicarelli (SUNY) などのもと、世界中のワークショップ、セミナー、シンポジウムなどで学ぶ。 　２０００年から嶋津武仁氏のもと、文部省研修作曲家として、日本に２年間滞在。日本の現代音楽に関する研究および活動を展開。 　日本滞在中に、コンピューターによるリアルタイムパフォーマンス／インプロバイゼーションに興味をもち、Roddy Schrock とともに、ラップトップデュオとしてTOGを結成。Mark Applebaum, Bevin Blectum, Kazumoto Endo, Fred Frith, BrentGutzeit, 中村としまる, Chris Penrose, 田中アタウ, 大友良英、などと競演。現在も日本および欧米において活躍中である。
　ロバート・ダックワ－スはソロ活動として、今春、日本ツアーを敢行。今後は 、Research Orientation invitation to STEIM（the Studio for Electro-Instrumental Music, アムステルダム. 2003年春）、TOG日本ツアー（2002.12）などを予定している。大学卒業後は、さらなる音楽活動の展開と日本語に磨きをかけるために、日本に戻り、慶應義塾大学、情報科学芸術大学院大学などで研究／活動を行う予定である。
website :: http://www.thing.net/~roddys/robert.html

徳井直生 (clickety and clack, PROGRESSIVE FOrM)
　1976年石川県出身東京都在住。タイトかつグルーヴィーでスピード感をともなった精度の高い４つ打トラックの制作を得意とするクリエーター／プログラマー。1998年、テクノのDJとして活動をスタートさせるのと同時にミニマル・テクノを中心とした楽曲制作にも着手する。2000年、C言語で書いた自作ソフトとAKAI MPC2000の組み合わせに限界を感じていた頃、音楽プログラミング環境Max/MSPに出会い、翌2001年にはMax/MSPでの音楽制作を本格的に開始。同時にMax/MSP上のソフト開発に取り組みはじめる。
　同年、ベルギーのレーベ ルPocket/Music Manより自身の1st12inch『Nao Tokui&TNT/We All need』を発表。ま た2002年にはスイスのレーベルSpeaker Attackよりリリースされたコンピレーション 『V.A/Deck Shark Series Vol.4』にも楽曲を提供し、今夏、clickety and clack 名義でPROGRESSIVE FOrMのあらたなアーティストとしてレーベルに合流する。
　またプログラマーでもある彼は大学において、人工生命 (Artificial Life)、複雑系 (Complex systems)などに関する研究に従事しており、進化的計算手法 (Evolutionary Computation)の音楽やデザインへの応用を模索している。現在は、これまでの研究結果を踏まえて、音楽・映像のための新しいビジュアル・プログラミング環境を開発中。人工生命的な「進化」(Evolution)および「創発」(Emergence)を重視したソフトウェアを今秋、公開予定。彼は「楽曲を制作する行為」と同様に「音楽のためのプログラムを書く行為」も等しくある種の「自己表現」だと主張し、「音楽作品」と「ソフトウェア・プログラミング」両方の側面からのアピールを実践している。
website :: http://www.miv.t.u-tokyo.ac.jp/~tokui/

青木孝允 (SILICOM, PROGRESSIVE FOrM)
　1976年大阪府出身。今年１月にリリースされた自身の2nd album『SILICOM two』が好評を博している、コンピューター/ソフトウェアを駆使する新世代クリエーター/音楽家。1994年頃より 『nexus6,5』名義による音楽製作を開始し、2000年2月より『AOKI takamasa』名義で現在へ至る。実験的かつ斬新なアプローチを取りながらもグルーヴ を保ちつつ繊細でいてかつどこか素朴な彼のサウンドの魅力は、コンピューター/エレクトロニクス・ミュージックと現代音楽との間を埋めるような、イノヴェイティヴ かつユニークなサウンドとそのスタイル、また「まるでコンピューターが生きてドラムを叩いているかのようなリズム」にある。
　2001年、PROGRESSIVE FOrMよりリリースされたソロ・アルバム AOKI takamasa/SILICOM(CD album/pfC_1)の他、半野喜弘氏の『april remixes』にもoval/markus popp、christophe charles、青柳拓次(little creatures)などのクリエーターとともに参加。ライブ・パフォーマンスにも定評があり、2001年はソロ・ライブを合わせると40回を超えるパフォーマンスを国内外(日本/フランス/トルコ)で行い高評を博す。特に11月にトルコで行われたIstanbul biennial 、12月にフランスで行われたbatofarへの参加は、特筆すべき点である。 2002年3月には、nbi club(ドイツ・ベルリン)にて、また"sepuku" radio libertaire 89.4/"songs of prise" radio aligre 93.1/"Audio" Radio FG 98.2などのフランス/パリのラジオステーションでのライブを行う。６月にはバルセロナで行われたSONAR 2002に出演、合わせてパリ、ベルリン、3都市計４回のライブも成功させる。
　また９月にはパリで行われるカルティエ財団のイベント、ローマで開かれるdissonanze festivalへはprefuse73(WARP)、retina(hefty)らとの出演も決定し、その他ロンドン及びベルリンでのイベントと合わせ、４都市５公演のライブを予定している。またリリースでは、半野喜弘氏の主催するCirqueよりリリース予定のコンピレーションへの参加、自身３枚目のアルバム、来冬予定で高木正勝及び小栗栖憲英とのコラボレーショ ン・アルバムのリリースなどを予定している。
website :: http://homepage.mac.com/silicom/

中居伊織
　1980年生まれ。京都府亀岡市出身。高校時代にジャパニーズポップスの影響を受け、シンセサイザーのプログラミング、作曲理論を独学で修得。その後、国際情報科学芸術アカデミー マルチメディア・スタジオ科に入学。電子機器を用いた表現方法を広く学ぶ。
　2001年、卒業制作として発表した"streetscape京都版"が好評を博し、フランス・ラヴァルにて開催された"Laval Virtual 2001"に"streetscapeパリ版"を出展。その後、立て続けに新作を発表。現在までに、京都、名古屋、パリ、六本木、仙台、世田谷、浜松の７都市で制作、各地で展示を行っている。
　そのほか、ソフトウェアデザイナーとしても活躍。トランペット演奏家の曽我部清典氏に数多くのプログラムを提供している。また、自身のライブパフォーマンスの為に制作した"meteorite"や"lapis"は、数多くのアーティストから賞賛の声があがっている。
　今後、自身の作曲活動を展開すると同時に、ソフトウェアデザインを通して、音楽の価値や制作手法に、何らかの改革をもたらそうと考えている。
website :: http://sound.jp/iorinakai/

中村滋延
1950年大阪生まれ。
1969年愛知県立芸術大学音楽学部作曲専攻入学。
1974～76年DAAD奨学生（西ドイツ政府給費生）として国立ミュンヘン音楽大学に留学。
1977年愛知県立芸大大学院修了。
日本音楽コンクール作曲部門２度の入賞（71，73年）をはじめ作曲コンクールの入賞入選多数。
クラシック音楽の系統に属する「現代音楽」が専門分野であり，作品数は100曲を超える。
作曲活動の特徴は視覚的要素を構成要素とした音楽作品の制作にある。視覚的要素として舞台上のパフォーマンスを扱った「ミュージックシアター」と，視覚要素として映像を扱った「映像音響詩」という２つの領域で活発な創作活動を行なっている。これらは視覚的要素と聴覚的要素の結びつきにコンピュータを積極的に応用することによって音楽系メディアアートとしても注目を集めている。
作品は日本国内のみでなく，ガウデアムス音楽祭（オランダ），ICMC（国際コンピュータ音楽会議），ＺＫＭ（ドイツ），モントルー合唱音楽祭（スイス），国際ビデオアート賞（ドイツ），ライトイメージパレルモビデオフェスティバル（イタリア），Vidarte（メキシコ）など，海外においても上演・上映・放送の機会が多い。
京都芸術短期大学映像専攻教授、京都造形芸術大学教授（映像・舞台芸術学科）、ドイツＺＫＭ（メディアアートセンター）客員芸術家，日本音楽コンクール（ＮＨＫ及び毎日新聞社主催）作曲部門審査員、等を経て、現在；九州芸術工科大学教授（音響設計学科）。
website :: http://www.kyushu-id.ac.jp/~sn/

コンピュータ音楽の楽しさと必要性を感じ、より深い勉強のため日本に渡り、現在　九州芸術工科大学　大学院　中村滋延研 究室で修学中である。最近は音楽だけではなく映像制作にも興味を持つようになり、作品制作範囲を広げている。

dumbo
1997年、松島大介と堀尾寛太によって結成された二人組。打楽器演奏と映像製作という二人の異なった背景をベースにしつつ、さまざまながらくたや簡単な仕掛けを用いたサウンド・パフォーマンスを始める。演奏／遊び、あるいは楽器／玩具など、どちらとも判断しかねるその作風は、アートやエンタテイメントといった輪郭をぼやけさせそれらをいったん留保し、「ただあるがままを観察する」ことによって生まれてくるものごとに焦点を当てる。
現在はコンピュータを取り込み、ギャラリーやクラブなどのスペースを中心に活動を続けている。

hecker (Germany/mego)
デジタルノイズ/パルスサウンドの最前衛、ウィーンのmegoレーベルを支える重要なアーティストが来日。megoはそもそもテクノレーベルとしてスタートしながらも、徹底したそのラディカルな姿勢によりダンスミュージックの突然変異体のようなサウンドばかりを次々とリリース、現在では完全に「テクノ」を逸脱し、全く新しいタイプの電子音響を生み出している。heckerはPITAと共にmegoの屋台骨を支えるアーティストであり、複雑に折り重なった電子ノイズを特徴としている。彼のRemixアルバム「[R*] iso|chall」ではジム・オルーク、刀根康尚、マウスオンマーズ、大友良英、オウテカといったそうそうたるメンバーが参加している。
website :: http://www.mego.at/

portable[k]ommunity + more.
前回freqにも登場し、レクチャーも行った彼らは、Max/MSP/nato.0+55、SuperColliderといったプログラミング環境、各種オーディオアプリケーションやハードウェアに対する圧倒的な知識量とスキルを背景にした、精緻な音響/映像プログラミングを行っている。それらをリアルタイムで構築・展開させ、最先端のDSP処理を取り入れつつも肉体性を伴った即興演奏を行っている。現在はACO(Sony Music)のニューアルバムのプロデュースや、企業と共同し様々な実験的イベントの企画、技術サポートなどを手がけている。VJとしての活動も行っており、競演したアーティストにはDJ Kenseiやhoon(坂本龍一＋半野善弘＋yasaka)、細野晴臣氏らがいる。
今回FREQでのレクチャーを担当する澤井妙治はこの秋 ARS ELECTORNICA(リンツ、オーストリア) や ICA(ロンドン)などで演奏、 さらに名古屋での ISEA(電子芸術国際会議) を経由しての FREQ 登場となる。
website :: http://www.portablekommunity.org/
