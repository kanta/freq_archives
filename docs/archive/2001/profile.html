portable[k]ommunity
堀切潤と澤井妙治の2人を中心とした音と映像のユニット。 Powerbook上で Max/MSP/nato.0+55 等のプログラミング環境を駆使し、portableに活動中。 現在CD制作中。

堀切潤　大阪在住。自由業。 大学にて哲学、IMI（インターメディウム研究所）ではサウンドデザインを学ぶ。卒業後、IMIでサウンド編集、Maxプログラミングのレクチャー等を行う。 最近の仕事としては、サロンマガジン主催(http://www.salon-magazine.net/)のデジタルワークショップにてMaxNatoレクチャーの講師、雑誌、net-flyer.com等での原稿執筆等など。

澤井妙治　奈良在住。装飾業。 10代中頃よりguitar, percussion, synthesizer などの楽器を演奏していたがメイン楽器を徐々にデジタル機器に移行。ここ数年は制作環境をPCに完全に移行し、 現在に至る。近頃のプロジェクトとしてはe~da(a.k.a.AOA, ex Boredoms)との最先端 のDSP処理を取り入れつつも肉体性を伴った即興演奏を目的としたものや、武蔵野美大の福田氏とのpulse音と電極を使ったインスタレーション作品の制作、今年６月に広島の宮島にて行われた世界聖なる音楽祭での民族楽器と Powerbook を使った live performance などがある。

九州芸術工科大学Maxゼミ
ドイツZKM(http://www.zkm.de/)等で活躍している作曲家 古川聖(現東京芸大助教授）氏 の講義に触発され2000年6月から活動を開始。MIDIやMax/MSPの基礎から始め，主に九州芸工大音響設計学科の学生を中心に作品製作や相互批評を行っている。現在は約月一回のペースで活動中。Maxのネーミング元であるマックス・マシューズ博士公認のゼミでもある。

vf：Fx (E,N,A + DJ Ryou)
COSPAR(宇宙空間研究委員会）の一員であり、ライブ時の操作性追求のため、Max/MSPを使用しているE,N,Aと、同じくCOSPARの一員であるDJ Ryouからなるユニット。”絶倫”（第3火曜 at STANDBOP)等で活動中。
E,N,A WebSite http://enoiseart.hoops.ne.jp/
COSPAR-WEB http://www.cospar-net.org/

中村 滋延 (なかむら しげのぶ)
作曲家・メディアアーティスト・九州芸術工科大学教授
1950年　大阪生まれ。
1969年　愛知県立芸術大学音楽学部作曲専攻入学。
1974～76年　DAAD奨学生（西ドイツ政府給費生）として国立ミュンヘン音楽大学に留学。
1977年　愛知県立芸大大学院修了。
1997～98年　ドイツＺＫＭ（メディアアートセンター）客員芸術家。
1999年及び2000年　日本音楽コンクール（ＮＨＫ及び毎日新聞社主催）作曲部門審査員。
現在　国立九州芸術工科大学教授（音響設計学科）、メディアシアター「時空」メンバー。

日本音楽コンクール作曲部門２度の入賞（71，73年）、国際ガウデアムス作曲コンクールオランダ放送局連盟賞、日本交響楽振興財団第1回作曲賞佳作入選、をはじめ作曲コンクールの入賞入選多数。
作曲活動の特徴は視覚的要素を構成要素とした音楽作品の制作にある。
視覚的要素として舞台上のパフォーマンスを扱った「ミュージックシアター」と、視覚要素として映像を扱った「映像音響詩」という２つの領域で活発な創作活動を行なっている。
これらは視覚的要素と聴覚的要素の結びつきにコンピュータを積極的に応用することによって音楽系メディアアートとしても注目を集めている。
作品は日本国内のみでなく、ガウデアムス音楽祭（オランダ）、ICMC（国際コンピュータ音楽会議），ＺＫＭ（ドイツ）、モントルー合唱音楽祭（スイス）、国際ビデオアート賞（現国際メディアアート賞、ドイツ）、ライトイメージパレルモビデオフェスティバル（イタリア）、Vidarte（メキシコ）、ソウル国際コンピュータ音楽フェスティバル（韓国）など、海外においても上演・上映・放送の機会が多い。
Web Site : http://www.tcn.zaq.ne.jp/s_nakamura/

小畑　郁男（こばたいくお）
長崎在住。作曲家・長崎純心大学短期大学部非常勤講師
1951年　長崎生まれ
1975年　九州芸術工科大学音響設計学科卒業。
1978年　国立音楽大学音楽学部楽理学科卒業。

フリーの作曲家として作曲活動を続ける一方、さまざまな時代の音楽に関心を持ち、AuRA（アウラ：女性グループ）の指揮者としてグレゴリオ聖歌・中世ポリフォニー音楽・近現代の作曲家の作品等を上演している。
近年は、コンピュータを用いた作曲・演奏を主として行い、その可能性を積極的に追求している。

dumbo
我々「dumbo」は松島大介と堀尾寛太の二人組です。
我々は「dumb」であり「づmぼ」でもあるんですが、
その耳はとても大きいので空も飛べるはずです。
活動経歴
1997.07 エレクトリックギターを解体しながら、手作りカリンバと融合させるライブパフォーマンス。
1998.07 扇風機と掃除機を用いたライヴ演奏。空気を送りだすものと吸い込むものという陰陽的セッション。
1998.11 スーパーボールでいろいろなものをこすったライブ演奏。アニミズム的なモノとの対話。
1999.06 自転車をインタフェイスに用い、自転車から見たノスタルジックな風景映像とノイズ音による非日常感とを止揚させたライヴ演奏。
1999.11 電子レンジや電気スタンドなどのスイッチを押すと、スクリーンに投影された電子が軌道上をまわり押された家電の音を奏でる。ちょっと感電。
　　　　　　　 活動休止。ユニット名を「dumbo」に改名。
2000.05 空の下かつ水の上でのアンビエント（に囲まれた）ライヴ。ようやく本格的に「Max/MSP」を使用。
今年の目標は路上に進出して、記号としてのアコギとタンバリンに対する演奏者と観衆の主客不一致問題の表層に浮遊する対象のノエマ的側面を脱臼させ観衆のドクサを現象学的還元によりエポケーさせることです。
